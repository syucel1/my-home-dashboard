# Dashboard mockups

Three design directions for the Home Hub browser dashboard. Open the `.html` files in a browser; they are responsive, so try a narrow window too. The `.png` files are 1440 px screenshots.

| Mockup | Direction | Best for |
|--------|-----------|----------|
| [A · Calm Control](mockup-a-calm-control.html) ([png](mockup-a-calm-control.png)) | Light theme, left sidebar, "Needs attention" strip, quick controls, room cards | Everyday use on laptop and phone; familiar app layout |
| [B · Night Console](mockup-b-night-console.html) ([png](mockup-b-night-console.png)) | Dark theme, large clock, tile grid with heating dial, live cameras, activity feed | Wall tablet / kiosk; glanceable from across the room |
| [C · Status Board](mockup-c-status-board.html) ([png](mockup-c-status-board.png)) | Warm neutral theme, top navigation, health summary, device table with 24 h health strips, inbox beside it | Health-first monitoring; spotting what is offline or degraded |

All three use the same sample data: printer offline, dehumidifier tank full, smoke alarm battery low, gate closed, heating 20.5° → 21.0°.
